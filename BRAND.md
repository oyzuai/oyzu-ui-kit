# Brand assets

Source: the authoritative Oyzu brand kit in the sibling public repository, docs/brand/assets, originating from oyzu-brand-kit-v1.zip.

public/brand contains unchanged copies of the supplied logo variants, icons and color tokens. src/brand/brand-colors.css is an unchanged copy of the supplied CSS tokens for bundling in the application and Storybook.

Use the color full logo on light surfaces at 160 CSS pixels wide or larger. Use the mark for compact placements. Preserve aspect ratios, transparent cutouts and clear space (about one quarter of the mark diameter). Do not redraw, recolor, rotate or apply effects to the artwork.

Official identity colors:

- Navy: #06144D
- Deep blue: #0A1DBB
- Bright blue: #0879FF

The interface uses deep blue for primary actions, navy for primary text, and derived cool neutrals for surfaces. These UI neutrals are provisional design choices, not additional official brand colors. Bright blue is an accent; text/control contrast must be checked for the actual background.

Assets retain their original ownership and license status. Copying them introduces no new license grant. Update copies from the authoritative kit instead of editing logo masters here.
